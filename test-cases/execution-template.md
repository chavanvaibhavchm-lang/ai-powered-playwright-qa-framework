# Manual execution record

Copy this template for a new execution; do not replace the saved automated evidence.

| Run information                          | Value |
| ---------------------------------------- | ----- |
| Run ID                                   |       |
| Tester                                   |       |
| Date/time and timezone                   |       |
| Browser/version                          |       |
| OS / viewport                            |       |
| Headed or headless                       |       |
| Application URL or companion service URL |       |
| Commit/build identifier (if available)   |       |

| Case ID                 | Actual result | Status  | Evidence link | Defect ID / notes |
| ----------------------- | ------------- | ------- | ------------- | ----------------- |
| Copy TC-ID from catalog |               | Not run |               |                   |

Allowed statuses: Not run, Passed, Failed, Blocked, Skipped, Defect reproduced.
Record why a case is skipped/blocked. For known-defect checks, “Defect reproduced”
means the broken behavior was observed; it is not a product acceptance pass.
Do not automatically copy a historical passing outcome into a new manual run.
